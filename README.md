# متتبع نافس

صفحة مجانية لأي مدرسة: بطاقة نافس، وملف الطلاب، والخطة العلاجية الفردية لكل طالب تُبنى من القياس القبلي وتُعدَّل بعد كل قياس، والتقرير الأسبوعي، وبنك الأسئلة والتصحيح، وجالب نور.

- كل البيانات تُحفظ في متصفح المستخدم على جهازه فقط (IndexedDB) ولا تُرسل إلى أي خادم.
- `jaleb.js`: جالب نور — يعمل داخل نظام نور بصلاحية مدير المدرسة (قراءة فقط) ويرسل البيانات إلى الصفحة في المتصفح نفسه.
